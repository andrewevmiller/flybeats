## Traps (the lasting ones belong in RUNBOOK)

- **Never train twice at once.** One epoch went from 76 s to 1,415 s. Check
  `scripts/runstat.ps1` first.
- **No GPU work without Andrew's go-ahead.**
- **Use `.venv\Scripts\python.exe`, from `git\`.** The parent folder is not the
  repo, and scheduled sessions start there.
- **Scheduled sessions stall on permission prompts** unless allow rules exist
  or someone is present.
- **An unattended session cannot start a script** (`powershell -File`,
  `Start-Process ... -File`): it always prompts. So local overnight runners
  are armed by hand and started by a GO file (`scripts\run_style_queue.ps1`).
- **Cloud and laptop numbers are not comparable.** Compare only runs from the
  same machine.
- **Windows Update restarts the laptop overnight.** Check the reboot keys
  before long runs.
